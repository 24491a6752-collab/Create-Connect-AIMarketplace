# CreateConnect AI — Creator Marketplace v5

Updated prototype based on the supplied marketplace/dashboard reference.

## New collaboration flow
1. Brand opens a creator card with **View profile**.
2. Creator profile shows AI portfolio, tools, workflow verification, commercial-use readiness, and response signal.
3. **Collaborate →** opens a structured collaboration request.
4. Request captures campaign/project, budget, deliverable format, deadline, commercial-use terms, workflow expectations, and message.
5. Sending the request adds it to the **Collaboration requests** inbox.
6. Pending requests can be accepted/rejected in the prototype; accepted requests can be opened as part of the engagement flow.

Existing features remain: AI portfolio discovery, category/tool/rights filters, creator search, AI brief builder, verification signals, commercial-use fields, and engagement pipeline.

Food/restaurant portfolio visuals continue to use remote Unsplash image URLs.
